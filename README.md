# hospital_management

For the test project, I want you to first research and propose an **end-to-end web solution for a single hospital**.

Do not start development immediately. First, understand how a hospital system should work and prepare a clear project idea covering the complete workflow, such as:

* Patient registration
* Doctors and departments
* Appointments
* Reception
* Patient visits
* Medical records
* Prescriptions
* Lab tests
* Pharmacy
* Billing and payments
* Hospital staff and roles
* Dashboard and reporting

You can suggest additional features based on your research.

The goal is to see how well you can research a real business problem, understand its workflows, design a proper solution, and then build it from frontend to backend.

Please prepare the project idea, major modules, user roles, workflows, and suggested tech stack before starting development.
